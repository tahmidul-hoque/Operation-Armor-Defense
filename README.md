# Operation: Armor Defense

**Operation: Armor Defense** is an action-packed 3D military tank shooter game. Put yourself in the commander's seat of a heavily armored tank to defend your central Command Base from a relentless enemy siege. Survive the onslaught, manage your resources, and break the enemy lines to achieve victory!

## 🎯 Objective
The enemy is swarming the central base. It is your job to protect it at all costs. 
* **Win Condition (Siege Survival):** Successfully destroy the enemy quota (50 tanks) while keeping the Command Base intact.
* **Lose Condition (Catastrophic Failure):** If your Tank Armor reaches 0% or the Command Base Structural Integrity is compromised, your tank is disabled and the siege is lost.

## ✨ Features

* **Independent Turret & Chassis Control:** Drive and steer the tank chassis with one hand while independently rotating the turret to aim with the other, aided by a projected laser sight.
* **Tactical Camera Toggle:** Seamlessly switch between a tactical third-person chase camera and an immersive first-person "Gunner View" mounted directly on the barrel.
* **Dual Ammunition Types:** 
  * **Primary:** Coaxial machine gun (Unlimited ammo, rapid-fire, low damage).
  * **Secondary:** Heavy High-Explosive (HE) shells (Limited ammo, area-of-effect damage).
* **Energy Dome Shield:** Deploy a temporary, damage-absorbing energy sphere around your tank to survive heavy crossfire.
* **Piercing Railgun (Cheat Mode):** Unleash a massive, instantly-destructive blue energy beam that ignores obstacles and vaporizes any enemy caught in its path.
* **Universal Collision Physics:** Dynamic collision detection ensures projectiles, enemies, the player, and environmental obstacles all interact realistically. Ramming enemies or walls will cause damage!
* **Dynamic Health Systems:** Keep an eye on three vital metrics: Player Tank Armor, Command Base Integrity, and Enemy Health.

## 🎮 Controls

* **W / S:** Drive Forward / Backward
* **A / D:** Steer Tank Chassis Left / Right
* **Left / Right Arrow Keys:** Rotate Turret Independently
* **Spacebar:** Fire Weapon
* **Q:** Switch Weapon (Primary Machine Gun / Secondary HE Shells)
* **E:** Toggle Energy Dome Shield
* **C:** Fire Piercing Railgun (Cheat Ability)
* **T:** Toggle Camera View (Third-Person / First-Person)
* **R:** Restart Game (After Win/Loss)

## 🛠️ Installation & Requirements

This game is built using Python and the PyOpenGL library. 

1. Ensure you have Python 3 installed.
2. Install the required dependencies:
   ```bash
   pip install PyOpenGL PyOpenGL_accelerate
   ```
3. Run the game:
   ```bash
   python game.py
   ```
